# Google Flow / Veo Asset Handoff

Folder ini menjembatani Google Flow/Veo ke Remotion.

## Cara pakai

1. Buka Google Labs Flow / Veo.
2. Buat clip sesuai `asset-manifest.json`.
3. Ekspor MP4 vertikal 9:16 bila memungkinkan.
4. Simpan ke `media/assets/flow/` dengan nama yang sama seperti `targetPath`.
5. Untuk screen recording situs, rekam manual lalu simpan ke path yang sama.
6. Jangan commit file video besar; cukup simpan lokal.

## Checklist lisensi

- [ ] Sumber aset dicatat (Flow sendiri / rekaman sendiri / stock).
- [ ] Lisensi komersial jelas.
- [ ] Tidak ada logo merek, wajah identifiable close-up tanpa izin, atau materi copyrighted.
- [ ] Landmark Semarang-familiar diverifikasi aman dipakai.
